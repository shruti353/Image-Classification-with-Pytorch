# MNIST Digit Classification with PyTorch


A convolutional neural network (CNN) implementation for MNIST digit classification achieving **99%+ accuracy**.

## 📊 Results
- **Test Accuracy**: 99.2%
- **Model Size**: ~1.2M parameters
- **Training Time**: ~2 minutes on GPU
